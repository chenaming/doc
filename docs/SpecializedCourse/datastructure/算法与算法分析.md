			事后统计法

		2.算法时间复杂度分析
			时间复杂度
				1. 问题规模和语句频度
					问题规模n
					算法执行时间≈所有语句执行时间之和=该语句的重复执行次数x执行一次所需的时间（设为单位时间）
					单位时间
						简单布尔或算术运算
						简单I/O
							指函数的输入/输出，例如，从数组读数据等操作
							不包括键盘文件等I/O
							函数返回
				2. 时间复杂度定义（算法渐进分析）
					这里将算法执行时间简化为“基本语句”的执行次数，与它同数量级，成正比
					引入大O记号
						从n0之后T(n)以Cf(n)为上限
					大Ω表示法
						从n0之后T(n)以Cf(n)为下限
					大theta表示法
						从n0之后以C1f(n)为下限，以C2f(n)为上限
				3. 时间复杂度分析举例
					递归算法时间复杂度
					非递归算法时间复杂度
						常量阶
							与问题规模n无关
						线性阶
						平方阶
						立方阶
							三重求和符号，自内向外
						对数阶
							先设基本语句的频度为f(n)，然后找出f(n)与n的关系
				4. 最好、最坏和平均时间复杂度
