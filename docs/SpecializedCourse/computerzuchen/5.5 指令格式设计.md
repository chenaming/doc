

# 5.5 指令格式设计

1.指令格式设计的主要内容

操作码字段，寻址方式，地址码字段
- 根据指令数量的要求及是否支持操作码扩展，确定操作码字段的位数
- 根据对操作数的要求确定地址码字段的个数
- 根据寻址方式的要求，为每个地址码字段确定寻址方式字段位数
- 确定采用定长指令还是变长指令

2.指令格式设计举例


> [!example]+
> 某机字长32位，采用三地址指令，支持8种寻址操作，完成60种操作，各寻址方式均可2K主存范围内取得操作数，并可在1K范围内
