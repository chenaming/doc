## 5.7.3 MIPS指令系统


1.MIPS指令概述

- MIPS（Microprocessor without Intellocked Pipleline Stages）是80年代初期由斯坦福大学Hennessy教授领导的研究小组研制成功
- 属于精简指令集计算机RISC（Reduced Instruction Set Computer）
- MIPS指令集有MIPS Ⅰ、MIPS Ⅱ，MIPS Ⅲ，MIPS Ⅳ，MIPS Ⅴ，MIPS32，和MIPS64多个版本
- 早期主要用于嵌入式系统，如Windows CE的设备，路由器，家用网关和视频游戏机，现在已经在PC机、服务器中得到广泛应用
- MIPS指令集有以下特点：
	- 简单的Load/Store结构
	- 易于流水线CPU设计
	- 易于编译器开发
	- MIPS指令的寻址方式非常简单，每条指令的操作也非常简单

3.MIPS寄存器

- 32个GPR
- 还有32个32位单精度浮点寄存器f0-f31

### 2. MIPS指令格式



2.MIPS指令格式概述

- 只有三种指令格式
	- R型指令
		- Rs,Rt分别为第一、二源操作数；Rd为目标操作数
	- I型指令
		- 双目、Load/Store:Rs和立即数是源操作数，Rt为目标操作数
		- 条件转移：Rs,Rt均为源操作数
	- J型指令
		- 26位立即数作为跳转目标地址的部分地址


1.R型指令
- 操作数和保存结果均通过寄存器进行；
	- op：操作码，所有R型指令中都全为0
	- rs：寄存器编号，对应第1个源操作数
	- rt：寄存器编号，对应第2个源操作数
	- rd：寄存器编号，据此保存结果
	- shamt：常数，在移位指令中使用
	- funct：功能码，指定指令的具体功能
- R型指令存在3种不同类型
	- 3寄存器R型指令
	- 2寄存器R型指令
	- 1寄存器R型指令

2.I型指令
- 操作数中设计立即数，结果保存到寄存器
	- op：标识指令的操作功能
	- rs：第1个源操作数，是寄存器操作数
	- rt：目的寄存器编号，用来保存运算结果
	- imm：第2个源操作数，立即数
- I型指令存在4种不同类型
	- 面向运算的I型指令
	- 面向访存的I型指令
	- 面向数位设置的I型指令
	- 面向条件转移（分支）的I型指令

### 3. MIPS指令寻址方式



4.MIPS寻址方式
- 在MIPS32指令集中，不单设寻址方式说明字段
	- R型指令：由op和funct字段共同隐含说明当前的寻址方式
	- I型和J型指令：由op字段隐含说明当前指令使用的寻址方式
- 立即数寻址（Immediate addressing）
	- addi s1,s2,10           ($s1<-\$2+E(10))
	- 注意：汇编格式和编码格式段的对应关系
- 寄存器直接寻址（Register Addressing）
- 基址寻址（Basic Addressing）
	- 使用基址寻址的指令：lw,sw,lh,sh,lb,lbu等
- 相对寻址
	- 使用相对寻址的指令：beq,bne
- 伪直接寻址（页面寻址）
	- J型指令
